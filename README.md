## 📲 How to Install & Use Offline on Phones

### Android (Chrome / Brave / Edge)
1. Open the web app URL.
2. Tap the **"Install App"** button banner, or tap `⋮` ➔ **"Install app"** / **"Add to Home screen"**.
3. Launch from your home screen — the entire app operates **100% offline** with zero internet connection!

### iPhone / iPad (Safari)
1. Open in Safari.
2. Tap the **Share** button (`⎋`).
3. Select **"Add to Home Screen"**.
